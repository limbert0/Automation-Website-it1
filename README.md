# Automy

The public site is the HTML files in this folder. Upload the folder, including `styles.css` and `site.js`, and point the domain at `index.html`.

Automy integrates AI into organisations that handle private records: data cleaning, desktop and mobile applications, websites, and security testing. The pages are Home, Services, Compliance, Accreditation, The team, and Contact. Fees are not on the public site.

`hello@automy.co.uk` is written on the site and is not a link. It will not receive mail until the domain is registered and the inbox exists.

Working notes that are not part of the public site are in `docs/`.
